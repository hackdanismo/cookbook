# Artificial Intelligence

## Large Language Model (LLM)
An `LLM` primary generates responses. Think of an `LLM` like a "brain" that understands information, reasons and generates responses. An `LLM` is a model. 

## Agent
An `AI agent` can use an `LLM` to make decisions, take actions, and work towards a goal. An agent is a system that uses a `model` to accomplish a task.
